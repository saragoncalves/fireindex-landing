# FireIndex — website institucional

Website institucional do FireIndex, desenvolvido com Next.js, TypeScript e Tailwind CSS.

## Desenvolvimento

```bash
npm install
npm run dev
```

Copie `.env.example` para `.env.local` para configurar o domínio e, opcionalmente, o envio de contactos por Resend. Sem estas variáveis, o formulário apresenta uma alternativa por email.

## Validação

```bash
npm run lint
npm run typecheck
npm run build
```
